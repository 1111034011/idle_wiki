# 團體介紹

## i-dle 是誰？
i-dle 是由 CUBE Entertainment 推出的韓國女子團體。官方 Profile 記載，團體於 2018 年 5 月以〈LATATA〉出道，團名讀作「아이들（i-deul）」，官方頁面介紹其概念包含五位成員個性聚集成團隊。舊作品和早期資料常使用「(G)I-DLE」名稱；2025 年官方活動回顧已使用 i-dle 名稱。

## 成員
目前官方 Profile 列出五位成員：

- [Miyeon](members/miyeon.md)
- [Minnie](members/minnie.md)
- [Soyeon](members/soyeon.md)
- [Yuqi](members/yuqi.md)
- [Shuhua](members/shuhua.md)

## 團體發展特色
官方網站將團體介紹為以 Soyeon 為中心參與詞曲創作及舞蹈編排的自我製作型團體。本站會把可查證的作品與活動列為事實；對作品風格或團體影響的說明，則作為編者整理，不取代官方說法。

## 名稱使用
本文在敘述目前團體時使用 i-dle；介紹早期作品或引用舊官方資料時保留原名稱 (G)I-DLE。兩種名稱在本網站的時間線中視為同一團體不同時期的名稱。
